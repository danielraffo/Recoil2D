Changes from my original design

The main idea is still the same. Shooting is the only way you move around. I ended up making it more of a wave survival game because it was more fun when there was always something coming after you.

I added a few enemy types so it was not just the same red enemy every time. The purple one takes more hits and the teal one splits into smaller enemies. I also added the blue ammo pickups because the game was way too annoying when you ran out. If you hit zero ammo you still get the junk shot so you can move. It can kill the red chasers and teal splitters, but it does no damage to the purple tanks.

I changed the look a lot too. I added the grid, glow, bullet trails, the aim line, score, best score, wave text and an ammo bar. I also added sounds and little hit effects so it did not feel like a blank test scene.

I changed the difficulty a few times while testing. The hard version was too much, but the easy one felt too slow. I put it somewhere in the middle. Enemies get a little faster every wave. They come in about every 0.95 seconds and there is around a 1.75 second break before the next wave. Each new wave also adds about one more enemy.

I also fixed some small stuff while testing. Enemies were spawning outside the visible board on wider screens, so I changed the spawn area to use the actual board. I also fixed the junk shot so it follows the rule I wanted instead of hurting everything or nothing.
